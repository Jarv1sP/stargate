| 职责 | 入口 |
| --- | --- |
| 提交、权限、额度、选节点 | `tasks/submit.mjs`、`job-submission.mjs`、`machine-selection.mjs` |
| 节点通信 | `execution-bridge.mjs` → `deploy/execution-worker.py` → `deploy/node-executor.py` |
| 后台同步、观察、取消 | `execution.mjs`、`job-observation.mjs`、`native-task-metadata.mjs` |
| 历史准备收尾 | `dataset-preparation.mjs`（只保留清理） |
| 持久工作区与原目录 | `deploy/project-store.py`、`personal-oci.py`、`local-data.py` |
| 排队、优先级、抢占、共享、弹性 | 现有 `gpuq/gpuq/`；不另造调度器或显卡分配账本 |
