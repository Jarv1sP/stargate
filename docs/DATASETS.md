# 数据集与传输

功能以[功能清单](FEATURES.md)为准，完整操作集中在[使用指南](USER_GUIDE.md)：

- [数据集](USER_GUIDE.md#数据集-data)：数据盘普通目录、上传续传、文件浏览与下载、服务器间复制、链接导入和云盘文件。
- [日志与结果](USER_GUIDE.md#日志与结果-results)：输出下载，以及项目、数据集和输出共用的 7 天回收站。
- [常见问题](USER_GUIDE.md#常见问题-troubleshooting)：传输中断、容量、维护和原编号查询。

网页对应入口为[数据集](/guide/data)。训练直接从本机 `/datasets` 读取，代码在 `/workspace`，结果写本任务 `/outputs`。

链接导入暂停或取消后，使用原 `IMPORT_ID` 续传并查询已传字节；不另建导入，也不删除临时文件。过期链接通过同一编号更新，目标目录和已传偏移保留。

服务器间复制接收进程中断时，状态查询和列表显示 `PAUSED` 并保留偏移，使用原 `COPY_ID` 续传。活动复制的进度观察直接读取最近落盘的记录，不等待文件写锁；状态观察只在确认接收进程停止、需要更新暂停状态时使用写锁。项目复制的等待、比较、传输和合并阶段见[项目开发指南](USER_GUIDE.md#项目开发-development)；进程状态读不到时显示未知，不自动重投。

接收进度不携带不断增长的逐文件上传索引；续传直接跳过已完成文件，已有上传编号和分片偏移保留。手动 `transfer resume` 沿原编号重启接收进程；正在合并的项目继续完成合并，取消和成功记录保持终态。源端准备阶段显示临时归档的实际字节，不计作网络已传字节。

节点间传输复用 TLS 连接，并及时发送小响应，减少逐文件往返中的小包等待；传输路线、原编号和分片偏移保持不变。

项目增量复制将相邻的小文件合并读取，每批不超过 1 MiB，批次内容先事务落盘再报告进度；重连后直接复用已完成批次。已有逐文件上传和大文件分片保持原偏移。合并仍等待目标项目空闲，目标独有文件保留。

支持字节范围的链接最多并发读取四块，每块 1 MiB，沿原偏移依次写入。失败后未提交的块重新读取，已连续落盘的字节保留；单连接源仍可正常导入。

本页提供数据集相关的仓库链接；完整操作步骤统一维护在使用指南。
