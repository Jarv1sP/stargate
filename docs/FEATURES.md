# STARGATE 功能清单

本文件是平台功能的唯一清单（2026-10-14 用户审定）。新增或删除功能须经仓库所有者批准后改本文件；代码以本文件为准。
原则：用最精简的做法满足功能，不画蛇添足。所有人的东西都共用。老数据不在平台里做任何适配，管理员自己 SSH 处理。

## 存储模型（每台服务器）
- 工作区：项目容器的代码、环境，挂在容器 /workspace。
- 数据集：每个数据集就是一个普通目录，所有人共用，挂在容器 /datasets；训练直接读。
- 没有 /data/mine，没有个人数据目录。
- 训练输出在 /outputs（每个任务独立）；容器内通过可读写 /job-outputs/任务ID 直接读取、复制和修改本机任务输出，沿用团队共享权限，原文件留在原处。

## 一、账号与成员
- 独立身份接入：配置统一身份服务后，门户集中注册、邀请码、密码及账号管理；计算平台与 mission 使用同一身份，业务平台之间不互调账号 API。
- 网页通过统一登录进入，CLI 仍可用统一用户名和密码登录；会话各平台独立。账号停用、应用撤权和密码修改会使旧登录失效。
- mission 不设置管理员；AMAX 管理员只管理计算业务，不自动成为统一门户、媒体或网络管理员。
- 统一门户负责账号、角色、停用、邀请码和应用授权；AMAX 保留成员卡数额度管理。接入配置与迁移要求见 [独立身份接入](../accounts/CENTRAL_IDENTITY.md)。

## 二、服务器与资源
- 各服务器 GPU 实时状态（型号、使用率、显存、温度、谁在用）、数据盘用量；节点每小时在低优先级后台统计项目文件、各项目任务输出，以及全部输出、容器环境、回收站和传输暂存占用，项目列表只读取带采样时间的缓存；部分可读保留用量下限，完全读不到才显示未知
- 切换服务器、看排队、平台总状态

## 三、项目（容器）与代码
- 新建项目（可填一个 Git 仓库地址，创建时自动克隆进 /workspace）、列出、切换、删除（进 7 天回收站，可恢复）
- 容器里自带 git，代码用 git 管理（pull/commit/push 用自己的 GitHub 凭据）
- 上传/下载文件到工作区（不带版本，断点续传）
- 跨服务器同步项目代码、HOME 和容器依赖文件；目标已有对应容器则复用并增量合并，首次才完整复制；异机调度无变化直接执行，有变化且目标忙或另一次复制占用时用独立任务副本，不等待也不改运行中作业的文件，副本在作业终态后台清理且不占用公共项目，取消传输不删除已交给调度器的副本；手动同步等待目标空闲再合并，保留目标独有文件，同路径旧内容进七天回收站
- 显示名、分组、归档/取消归档、查看项目磁盘配额
- 同机指定新名字复制项目，后台导出不阻塞传输创建、查询或取消
- 复制失败或取消会释放两端暂存；每小时清理已结束的导出，以及超过 24 小时无人读取的导出和接收暂存，过期后沿原编号重新导出，活跃续传和运行中任务副本保留

## 四、终端
- 网页和 CLI 打开项目终端，断开重连、接管
- 带 GPU 的交互终端
- 容器网络诊断

## 五、训练任务
- 提交任务（指定卡数、自动选服务器、指定 GPU），直接用当前工作区和 /datasets
- 作业依赖（CLI --after，可重复或逗号分隔）：全部成功后同机按优先级调度，失败/取消自动取消；链内共用预留
- 任务列表、日志、实时跟踪、诊断（CPU/内存/OOM）
- 取消、优先级、完成情况、资源收尾
- 任务显示名、留言、通知
- 训练进度上报、checkpoint 断点重跑（SDK）
- 训练输出：浏览、下载、删除（进回收站，可恢复）

## 六、数据集（数据盘上的普通目录）
- 列出数据集（名字、大小、上传人、修改时间）、浏览文件
- 上传（新建或往已有数据集里加，断点续传）、下载
- 删除（进 7 天回收站，可恢复）
- 复制到别的服务器

## 七、传输与导入
- 服务器之间传输、电脑上传下载、校园网直连；列表、状态、取消、续传
- 目录下载按清单大小收齐每个文件后才完成，大小不符保留进度并暂停
- 阿里云盘分享导入、HTTPS 链接导入
- 服务器上的云盘文件：浏览、下载到数据集目录或工作区、把服务器上的文件上传到云盘

## 八、协作
- 帖子、评论、聊天、置顶、任务留言
- 聊天：回车发送、@成员提醒（被 @ 的人打开网站时弹窗，像公告一样）、常用表情、发送图片（浏览器压缩后不超过 700 KB，随消息保留 30 天，总量超过 256 MiB 时先清最早的图片）
- 私密聊天室：管理员可在实验室聊天下面新建，只有被拉进来的人看得见；群主设聊天室管理员，群主和管理员可以拉人、移出成员、改名；群主可删除聊天室（聊天记录和图片一起删除）；聊天标题下一行按钮切换实验室聊天和私密聊天室；功能与实验室聊天相同
- 公告：定向发送、弹窗、外观、CLI 未读提醒和已读确认

## 九、管理台（管理员）
- 只有三块：成员与额度（审批、每台最多与同时最多用卡）、维护模式（全平台/单台，填写原因）、云盘连接（阿里云盘扫码连接、重新授权、断开）
- 账号、角色和停用在统一门户管理，管理台只显示角色

## 十、其他
- 使用指南、帮助、CLI 安装（Linux/Windows/macOS）与更新
- 创意工坊：团队共享发布主题/布局和隔离运行的小组件/整站界面，预览、按账号安装/停用、手动更新、恢复默认。内置浅色紧凑和 AISpace 参考布局，安装只改变自己的界面；授权后的项目、数据和任务操作复用现有后端，不另建调度或容器流程；整站界面安装后自动替换整个可见页面，保留恢复平台入口。

## 删除的功能（用户定）
- 管理员接管旧账号数据（admin adopt）
- 长期归档、归档登记、缓存保护（pin/unpin）、存储计划、数据退役/authority、注销登记
- 数据集版本（NAME@VERSION、upload version、prepare、warehouse、缓存层）
- 代码版本：发布（publish/release）、固定版本运行（--release）、快照、代码同步清单（sync code/git 快照）、按版本复制项目
- /data/mine、个人数据目录、数据整理区（data shell/publish）
- 任何老数据迁移/适配/兼容代码，包括“从服务器已有路径导入项目”（project import）
- 旧客户端兼容（旧 CLI 只回一句升级提示）
- 平台内的宿主 root 命令行（ssh --root、exec）
- 管理台里的显卡与任务、主机诊断、维护区重复的服务器列表、额度加减按钮（算力、任务·全部和「编辑」已覆盖）
