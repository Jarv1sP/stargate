# 工坊整站界面

插件作品可设置 `presentation: "interface"`。安装后自动替换整个可见门户，
未填写此字段的插件仍显示为小组件。作品沿用 opaque-origin iframe、CSP 和声明权限，
拿不到平台登录凭据，也不能直接连接节点或系统盘。

同一账号只启用一个整站界面，保留原有主题及普通插件。
按 **Ctrl + Alt + 0** 停用当前整站作品并恢复平台，焦点在隔离界面或终端内也有效。
页面不增加回退按钮；异常时可手动进入 `?workshop=off#workshop`。
底层门户在整站界面运行时不可交互，停用或退出账号时恢复。

## 仓浪真实工作界面

```sh
node scripts/package-ceake-live.mjs out/ceake-live/仓浪平台_真实后端.json
```

源码位于 `workshop-apps/ceake/`。生成包安装即打开，直接调用当前平台，不包含模拟状态机或种子数据。

| 仓浪入口 | 当前平台实现 |
| --- | --- |
| 资源池 | 清单内服务器、真实 GPU 指标；原生算力与存储详情 |
| 项目空间 | 团队项目列表、新建 OCI 项目、设置、删除入七天回收站 |
| Notebook | 项目真实终端和文件面板；不伪造 Jupyter 服务 |
| 训练作业 | 团队任务、提交/指定卡数/自动选机、原生高级提交、取消、优先级、显示名称、日志、诊断、留言 |
| 输出 | 原生任务输出浏览/下载/删除 |
| 数据集管理 | 共享目录列表、真实文件上传下载、删除及恢复 |
| 回收站 | 查询现有条目并按原编号恢复 |
| 管理台/协作/传输 | 当前平台原生面板和既有角色权限 |

AutoML、独立模型市场、镜像保存、旧数据版本等没有当前接口的功能会明确说明，
不再生成模拟记录或假成功；可从相关页面进入现有项目/训练功能。
任务采用实际 submitter 姓名及顶层或 latestAttempt 时间字段。
监控过期、节点读取失败和状态未知不会显示成空闲或零；长列表保留筛选和分页。

## 接口与原生面板

作品声明的能力：

- `platform.read`：`stargate.call('platform.read', {operation, args})`，读取团队项目、任务、日志、数据集等。
  `operation: 'state'` 返回限定的账号公开字段、任务和资源视图，不传 session token 或账号密钥。
- `platform.write`：同样结构转发既有项目/任务/数据管理操作。不会重写后端或自动重试写请求。
- `platform.ui`：打开固定的项目、数据集、任务、资源、协作、传输或管理台原生面板。
  终端输入、上传下载、校园网直连/续传、云盘与管理员操作沿用原控制器，不把令牌交给插件。
- `jobs.cancel`：沿用平台已有的取消确认；不叠加第二次确认。

转发范围见 `dist/workshop-platform.js`。它复用 `store.call`，所以登录、管理员权限、
配额、回收站和系统盘隔离仍由现有后端执行。原生面板只是临时移动已有 DOM，关闭后归位，
不复制一份终端或传输实现。新建项目未出现在目录缓存时，复用现有刷新后再打开目标项目。

提交/删除使用原 key 和原请求处理未知结果；上次提交不明确时仍可明确选择另建独立任务，不会取消或重放原请求；只有明确的 `TRASHED` / `RESTORED` 才显示完成。
真实工作界面与只读小组件的权限分开；普通 `jobs.read` 小组件仍保持原接口语义。

## 验证

- `tests/workshop-platform.test.js`：团队数据投影、凭据不暴露、接口能力范围、原请求转发。
- `tests/ceake-live-ui-smoke.mjs`：真实前端/工坊/原生面板配合隔离 RPC，覆盖项目创建、
  缓存后新项目、终端/文件/输出/数据集面板、提交回执丢失的原 key 重试、日志、留言/取消、删除未知状态与恢复。
  `CEAKE_ROLE=member` 可复查成员路径。
- 既有工坊 API、frame、runtime、HTTP 和整站安装/快捷键测试继续覆盖基础行为。

生产验收只读取现有项目、任务与日志，不用现役任务测试提交、取消或删除。
PDF、原 ZIP、真实数据截图和生成作品包不进公开仓库。
